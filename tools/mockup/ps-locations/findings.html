SOS data

  • The game records which Pokémon calls which ally (each slot has its own allies), so the guide can say "Corsola calls Mareanie" exactly. The build used to keep one list per table and only showed allies for Pokémon found nowhere else.
  • The doc shows SOS as a separate table on some pages and as Ally columns on others; the game data is the same everywhere, so the guide can be consistent.
  • Weather allies (any Pokémon in rain, sand or hail: Castform, Goomy, Sliggoo, Vanillite...) are in the game data too, not only in the doc.
  • Doc vs game on callers: they agree, apart from Crabrawler → Crabominable on Routes 15 and 16 (doc only). The doc can't show forms: its red "Rattata" ally of Rattata is the Kantonian one.

Bugs in today's guide

  • Route 1 Grass 2 and Grass 3 rates are doubled (Scatterbug 30% where the game has 15%): the game keeps the same table in two areas and the build added them up.
  • East Sea Shellos (an SOS ally of West Sea Shellos on Route 1) isn't listed anywhere.
  • Poni Grove lists Stakataka and Blacephalon from a 0% slot. They aren't wild there.
  • Brooklet Hill's plain fishing spot is labelled bubbling, because the doc's level range doesn't match the game's. The new build picks bubbling as the higher-level copy in the game data.
  • One section is called "11Cave" (Seaward Cave), from a page number in the doc.

Doc vs game (the game is shown)

  • Fishing rates differ on Route 7 (game: Staryu 50, Relicanth 30; doc 25, 10), Route 9 (Luvdisc 80; doc 50), Akala Outskirts (Clauncher and Skrelp 30; doc 15), Seafolk Village (Dhelmise 50; doc 5), Poni Breaker Coast, Malie Garden (Goldeen and Seaking swapped by spot) and Hau'oli City bubbling.
  • Grass rates differ on Route 5 (Yanma 10; doc 15), Brooklet Hill (Paras, Morelull 20; doc 15), Ula'ula Meadow (Lilligant and Whimsicott change at night), Vast Poni Canyon (Mienshao 10, plus Boldore the doc doesn't list), Poni Meadow (Oricorio 20), Route 16 (Pelipper 20), Ancient Poni Path (Gastrodon 30), Thrifty Megamart (Rotom 10, Klefki 20).
  • Levels differ: Verdant Cavern 10–13 (doc 8–11), its dust clouds 12, Route 3 shadows 11–14, Route 8 surfing 27–30 (doc 21–24), and most bubbling spots run a few levels higher than the doc says.
  • Species: Poni Wilds berry piles are half Crabrawler, half Shuckle (doc: Shuckle only). Route 1's night Corsola 20% is on the bubbling spot in the game; the doc puts it on the plain rod.
